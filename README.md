### 🛠️ Proyecto destacado

#### 🛡️ [ARGOS MERC-PD](https://github.com/mateoenriquez/kushki_mercpd_project)
Sistema web para automatizar la metodología **MERC-PD** de evaluación de riesgos cibernéticos y protección de datos, desarrollado como proyecto integrador de la materia de Seguridad Informática (caso aplicado: Kushki).

- Registro y valoración de activos mediante la tríada **CIA** (Confidencialidad, Integridad, Disponibilidad).
- Identificación de riesgos con cálculo automático de **riesgo inherente y residual**, clasificado en 5 niveles con SLA por nivel.
- Módulo de tratamientos (Mitigar / Transferir / Evitar / Aceptar) con reglas de negocio que bloquean aceptaciones indebidas.
- Dashboard ejecutivo con KPIs, matriz de calor y semáforo de riesgo en tiempo real.
- Auditoría completa de acciones y exportación de reportes en CSV.
- Documento de respaldo técnico con arquitectura, modelo de datos, reglas MERC-PD y evidencias del sistema.

**Stack:** `Django` · `SQL Server` · `mssql-django` · `pyodbc` · `Chart.js` · `Waitress` · `WhiteNoise` · `Cloudflare Tunnel`

### 📂 Otros proyectos

#### 🎵 [RollsMusic](https://github.com/valemolina567/RollsMusic)
Plataforma de streaming musical construida en equipo, migrando el modelo de datos de SQL Server hacia MongoDB.

- Resolución de conflictos de merge complejos entre una rama completamente migrada a MongoDB y una rama legacy en SQL Server.
- Depuración de consultas PyMongo y ajuste de la capa de vistas para aplanar datos entre ambos modelos.
- Corrección de incompatibilidades de tipos en IDs de artista (enteros de SQL vs. `ObjectId` de Mongo) y de bugs silenciosos en la creación de álbumes.
- Función auxiliar compartida para estandarizar las búsquedas de artistas entre vistas.

**Stack:** `Django` · `MongoDB` · `PyMongo` · `SQL Server`
